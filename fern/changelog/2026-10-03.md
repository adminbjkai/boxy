---
title: "v1.6.0 — A clearer workspace, lighter transfers"
---

Boxy gains a refreshed workspace, pinned folders, mobile folder access, folder summaries,
Refresh, and clear-all filters while retaining its existing file operations.

Downloads now stream with range support. ZIP creation uses temporary disk files, thumbnail
decoding is bounded, and storage totals share an invalidated cache. Live refreshes coalesce.

The editor flushes pending saves on close and retains content after failed saves. Markdown
previews are sanitized. Exact browser-upload filenames and encoded folder links work correctly.
Nested upload symlink escapes and archive symlink traversal are blocked.

Frontend files are split by concern but remain embedded in one binary. CI covers isolated
browser/API workflows; deployment preserves a rollback binary and verifies the public app.

See the repository CHANGELOG for the full release notes.
