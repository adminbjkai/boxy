## v1.3.0 & v1.2.0 — Previews, offline vendoring, motion UI

### Added (v1.3.0)
- **File previews** — PDF (embedded viewer), video and audio players in a media preview modal; AVIF support
- Connection-loss banner with auto-reconnect status; API errors surface the server's actual message in toasts
- Rust unit tests: path-traversal safety, filename dedup, name validation
- **Vendored Prism.js, marked.js and web fonts** — zero third-party runtime requests, works fully offline

### Fixed (v1.3.0)
- Escaped raw file extension in icon rendering (XSS hardening)

### Added (v1.2.0)
- **Motion UI overhaul** — WebSocket-driven item animations, full-viewport drag-and-drop upload overlay, per-file upload progress, modal blur/scale transitions, animated empty state
- Mobile polish: ≤480 px responsive layout, ≥40 px tap targets on touch devices
- All motion respects `prefers-reduced-motion`; animations are transform/opacity-only
