## v1.5.0 — Documentation site, Docs button, Docker fix

### Added
- **This documentation site** — guides with real app screenshots, a full OpenAPI API
  reference at [api.boxy.bjk.ai](https://api.boxy.bjk.ai), and this changelog
- **Docs button** in the app header linking here (opens in a new tab)

### Fixed
- Dockerfile now sets `BOX_BIND_ADDR=0.0.0.0` — previously the container bound
  127.0.0.1, so `docker run -p 8086:8086` published a dead port

### Known issues (documented)
- `BOX_MAX_UPLOAD_BYTES` is not enforced by the app; the effective upload cap is the
  reverse proxy's `client_max_body_size`
- ZIP streaming walks are not depth-capped (unlike folder/search/stats walks)
